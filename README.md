# Book Vibe Tracker – Discover, Track, Read
**Your personal book dashboard. Track what you've read. Wishlist what's next.**

🔗 [Live Demo](https://book-vibe-tracker.netlify.app/)

---

## The Problem
Readers want to discover new books, track what they've read, and see their reading progress — but most apps are clunky or require a backend. You need something fast, beautiful, and works offline.

## The Solution
Book Vibe Tracker gives you:
- **Browse curated books** — Detailed info, reviews, ratings, year published  
- **Mark as Read** — One click, instant state update  
- **Build a Wishlist** — Save books for later  
- **See your progress** — Interactive chart of total pages read  
- **Data persists** — All tracking survives browser closes  
- **Shop directly** — Links to buy on Amazon  

---

## What I Built
✅ **React Context for global state** — Read list & wishlist sync across all pages  
✅ **Dynamic routing** — React Router with book detail pages by ID  
✅ **Interactive analytics** — Recharts area chart of reading progress  
✅ **localStorage persistence** — Zero data loss on refresh  
✅ **Toast notifications** — React Toastify for user feedback  
✅ **Professional UI** — Tailwind + DaisyUI, fully responsive

## How to Run
```bash
git clone <repo>
cd book-vibe-tracker
npm install
npm run dev
```

Visit [http://localhost:5173](http://localhost:5173)
